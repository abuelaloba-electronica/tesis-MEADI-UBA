Conexión con el dispositivo
Sin conexión
Este navegador no soporta Web Serial API. Probá con Chrome o Edge de escritorio.
El clic en este botón también habilita el audio: los navegadores exigen un gesto del usuario para arrancar el sonido.
Calibración de intensidad
El sketch manda el pico crudo del piezo (0–1023). Este rango es el que se estira a 0–1 para el volumen, el brillo y el tamaño del círculo. Ajustarlo tocando.
Color de las dos familias
Dedo 0 se dibuja como disco relleno; dedo 1, como anillo. Forma y color se distinguen aun superpuestos.
Audio
Teclas A y L disparan los dedos 0 y 1 sin la placa (intensidad al azar), y F mantenida simula la presión del FSR. Sirve para ajustar el timbre sin el guante.
